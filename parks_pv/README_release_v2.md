# parks_pv_v1 — synthetic AC power of 90 real MaStR open-ground PV parks

Generated by `scripts/pv/run_parks_pv_v1.py` (generator repo, branch `pv-v1`, package `parks_pv/` on top of
`pv/`); report `~/Work/FL_Contribution/reports/pv_park_synthesis_v1.md`.

- Park = MaStR Lokation (`park_id` = `LokationMaStRNummer`; Lokationen of one operator within 500 m merged,
  members in the manifest), selection `FL_Contribution/data/mastr/pv_park_selection_v1.csv`.
- Chain **PVWatts-P + cams_bc**: CAMS radiation (ADS, 15 min, centre + 8 ring points at 3/8 km) corrected
  at the park point by the cams_bc model (XGBoost ensemble of three station folds, `models/xgb_v5`) →
  closure DNI with clear-sky cap → Hay-Davies per sub-array with PVGIS horizon and inter-row shading
  (GCR from kWp/ha) → physical IAM → Faiman cell temperature → PVWatts DC with era gamma → era aging
  (LID + linear + late) → DC losses 5 % → PVWatts inverter clipping at the AC rating (until 2026-10-23 at 0.97 × AC) → AC losses 2 %,
  availability 0.98 → ERA5 snow depth factor (coverage = depth / 5 cm). No curtailment, no soiling.
- Hourly means, UTC, **label = interval start** (as the meters; DWD/CAMS/ERA5 sources label the end and
  were shifted), 2023-07-24 00:00 → 2026-07-31 23:00; a park commissioned later starts when its last MaStR unit is in
  operation (`parks.csv:history_start`, since 2026-10-23; earlier releases ran every park over the whole window).
- Truth vs register: `pv_arrays.csv` holds the TRUE sub-arrays (terrain-following tilt/azimuth, shares);
  `pv_masterdata_view.csv` holds what a register delivers (MaStR classes, tilt rounded to 5°, secondary
  orientation only where MaStR has it). In ~15 % of the parks the true main orientation deliberately
  differs from the registered class (`parks.csv:register_deviation`).

## Files

| file | content |
|---|---|
| `synth_<park_id>.parquet` | hourly time series (columns below) |
| `manifest_<park_id>.json` | chain config, params, arrays, site, SHA256 of CAMS CSVs / corrected product / ERA5 pulls / snow point series / config / horizon, git state, release SHA256 |
| `parks.csv` | one row per park (capacity AC/DC, class, client, region, cohort, terrain, register classes, deviation flag, CF, clipping and snow shares) |
| `pv_arrays.csv` | one row per true sub-array: tilt, azimuth, share, kWp, mount angles, module era, gamma, DC/AC, GCR |
| `pv_masterdata_view.csv` | register view of the same parks |
| `clients.csv` | 4 regional + 4 nationwide clients + holdout |
| `sites.csv` | centroid, DEM terrain metrics, footprint source/area, true mean angles, horizon source |

## Columns of `synth_<park_id>.parquet`

| column | unit | meaning |
|---|---|---|
| `ghi`, `dhi` | W/m² | corrected CAMS at the park (chain input); raw CAMS where the correction had no input (`imputed_share` = 1) |
| `ghi_cams_raw`, `dhi_cams_raw`, `ghi_clear_cams` | W/m² | raw CAMS all-sky and McClear clear-sky |
| `ghi_era5` | W/m² | ERA5 ssrd of the nearest cell (reference) |
| `temp_air`, `wind_speed`, `pressure` | °C, m/s, Pa | ERA5 nearest cell, interval means |
| `albedo` | – | ERA5 forecast albedo (fal) |
| `snow_depth_cm` | cm | ERA5 physical snow depth (sd / rsn) |
| `imputed_share`, `ring_missing` | – | 1 where the corrected product fell back to raw CAMS / the CAMS ring was incomplete |
| `dni`, `zenith`, `azimuth_sun` | W/m², °, ° | closure DNI, solar position at the interval centre |
| `poa_global`, `poa_eff` | W/m² | capacity-weighted plane-of-array irradiance before / after shading and IAM |
| `t_cell` | °C | capacity-weighted cell temperature |
| `p_dc_raw_w`, `aging_factor`, `p_dc_w` | W, –, W | DC before aging/losses, aging factor, DC at the inverter |
| `clipped` | – | 1 where the inverter limits (DC × 0.97 > AC rating) |
| `horizon_shaded` | – | share of beam blocked by the horizon |
| `snow_coverage`, `snow_factor` | – | ERA5 snow coverage and resulting power factor |
| `power_park_free` | W | AC power before snow |
| `power_park` | W | `power_park_free × snow_factor` — the target |
| `availability` | – | placeholder 1.0 (the constant 0.98 is inside the chain; outage/curtailment masks are a later stage) |

Capacity for normalisation: `parks.csv:capacity_kw` = Σ MaStR Nettonennleistung (AC);
`capacity_kwp_dc` = Σ Bruttoleistung (DC).
