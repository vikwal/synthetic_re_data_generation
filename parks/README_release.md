# parks_v1 — synthetic power of 90 real MaStR wind parks

Generated by `scripts/parks/run_parks_v1.py` (generator repo, branch `parks-v1`);
chain config `configs/round2/PARKS_v1.yaml`; report
`~/Work/FL_Contribution/reports/park_synthesis_v1.md`.

- Park = MaStR Lokation (`park_id` = `LokationMaStRNummer`), selection
  `FL_Contribution/data/mastr/wind_park_selection_v1_1.csv`.
- Chain **M4-noQM**: ERA5 (Postgres `public.era5_wind_grid`, nearest 0.25° cell per
  turbine group) → dynamic power law to hub height → real library power curve with
  hub density → Weibull aging per group (λ 54.5 y, κ 2) → rating cap
  min(MaStR net rating, curve max) → NOJ wakes (PyWake, k 0.075, real layouts).
  No QM correction, no noise, no availability/curtailment model yet.
- Hourly, UTC, 2023-07-24 00:00 → 2026-08-31 23:00 (27,240 h).

## Files

| file | content |
|---|---|
| `synth_<park_id>.parquet` | hourly time series (columns below) |
| `manifest_<park_id>.json` | chain config, groups, ERA5 cells + SHA256 of the DB pull, wake k/efficiency, git state, release SHA256 |
| `parks.csv` | one row per park (federated_setting.md §7 + extras: OSM status, hybrid-gate info, wake efficiency, CF) |
| `wind_groups.csv` | one row per turbine group (type, n, hub, rotor, rating, cap, commissioning, ERA5 cell, aging factors) |
| `clients.csv` | 4 regional + 4 nationwide clients + holdout |
| `sites.csv` | park centroid, terrain metrics (DEM/CORINE), primary ERA5 cell |
| `park_layouts.csv` | one row per turbine: coordinates used (MaStR or OSM-corrected), UTM32, group |
| `turbine_specs_overrides.csv` | cut-in/cut-out/rated wind speeds derived from the curve where the library has '-' |

## Columns of `synth_<park_id>.parquet`

| column | unit | meaning |
|---|---|---|
| `u_wind_10m`, `v_wind_10m`, `u_wind_100m`, `v_wind_100m`, `wind_gust_10m` | m/s | ERA5, primary cell (largest capacity share) |
| `friction_wind` | m/s | ERA5 friction velocity |
| `temp_2m`, `dew_point_2m` | K | ERA5 |
| `pressure` | Pa | ERA5 surface pressure |
| `wind_speed_100m`, `relhum`, `sat_vap_pressure`, `density` | m/s, –, Pa, kg/m³ | derived at the primary cell (2 m density) |
| `wind_speed_hub_t<i>` | m/s | hub-height wind of group i (its own ERA5 cell) |
| `wind_direction_100m_t<i>` | ° (from) | ERA5 100 m direction of group i's cell |
| `density_hub_t<i>` | kg/m³ | hub-height density of group i |
| `aging_factor_t<i>` | – | Weibull retained load factor of group i |
| `power_t<i>` | W | free-stream power of group i, **group total** (n turbines) |
| `power_park_free` | W | Σ `power_t<i>` |
| `wake_factor` | – | NOJ w(t) = P_waked / P_free ∈ (0, 1] |
| `power_park` | W | `power_park_free × wake_factor` — the target |
| `availability` | – | placeholder, 1.0 (availability/outage mask comes later) |

Capacity for normalisation: `parks.csv:capacity_kw` = Σ MaStR net ratings.
`capacity_cap_kw` is the most the simulated park can deliver (real curves are never
rescaled, so units registered above their curve maximum stay at the curve maximum).
