# {release} — synthetic AC power of real MaStR open-ground PV parks

Generated by `generate_pv.py --config {config}` (repo `synthetic_re_data_generation`) on {date}; {n_parks} parks,
variant `{variant}`. The manifest of every park holds the run config, the git state and the SHA256 of all inputs.

- Park = MaStR Lokation (`park_id`; Lokationen of one operator within 500 m merged, members in the manifest).
- Window {start} → {end} (exclusive), step {step}, UTC, **label = interval start**; a park starts when its last MaStR
  unit is in operation (`parks.csv:history_start`).
- Chain **PVWatts-P + cams_bc**: CAMS radiation (ADS, 15 min, centre + 8 ring points at 3/8 km) corrected at the park
  point by the cams_bc model `{correction}` (XGBoost ensemble of three station folds) → closure DNI with clear-sky cap →
  Hay-Davies per sub-array with horizon ({horizon}) and inter-row shading (GCR from kWp/ha) → physical IAM → Faiman cell
  temperature → PVWatts DC with era gamma → aging (LID + linear + late; age cohorts of the MaStR units: {cohorts}) →
  DC losses 5 % → PVWatts inverter clipping at the AC rating → AC losses 2 %, availability 0.98 → snow factor. No
  curtailment, no soiling.
- Snow: {snow}
- Geometry (`pv_arrays.csv:geometry_source`):
  - `windows:<source>` ({n_windows} parks): sub-arrays measured by the window method (`pv/geodata_windows.py`) on the
    state surface model (point cloud, laser DOM1, or image DSM); tilt against the horizontal, true azimuth, share =
    table area; east-west parks as two arrays perpendicular to the row axis.
  - otherwise ({n_fallback} parks): the register geometry (MaStR classes and era, terrain-following on DGM1 or GLO-30).
- Truth vs register: `pv_arrays.csv` holds the TRUE sub-arrays; `pv_masterdata_view.csv` what a register delivers
  (MaStR classes, tilt rounded to 5°, secondary orientation only where MaStR has it). `sites.csv:register_deviation`
  names measured deviations from the registered class (`... (geodata)`).

## Files

| file | content |
|---|---|
| `synth_<park_id>.parquet` | time series (columns below) |
| `manifest_<park_id>.json` | run config, chain config, params, arrays, site, SHA256 of CAMS CSVs / corrected product / ERA5 pulls / snow series / config / horizon, git state, release SHA256 |
| `parks.csv` | one row per park (capacity AC/DC, class, client, region, cohort, terrain, register classes, deviation flag, CF, clipping and snow shares) |
| `pv_arrays.csv` | one row per true sub-array: tilt, azimuth, share, kWp, mount angles, source, module era, gamma, DC/AC, GCR |
| `pv_masterdata_view.csv` | register view of the same parks |
| `clients.csv` | clients of the federated setting |
| `sites.csv` | centroid, DEM terrain metrics, footprint source/area, true mean angles, horizon source, geometry source |

## Columns of `synth_<park_id>.parquet`

| column | unit | meaning |
|---|---|---|
| `ghi`, `dhi` | W/m² | corrected CAMS at the park (chain input); raw CAMS where the correction had no input (`imputed_share` = 1) |
| `ghi_cams_raw`, `dhi_cams_raw`, `ghi_clear_cams` | W/m² | raw CAMS all-sky and McClear clear-sky |
| `ghi_era5` | W/m² | ERA5 ssrd of the nearest cell (reference) |
| `temp_air`, `wind_speed`, `pressure` | °C, m/s, Pa | ERA5 nearest cell, interval means |
| `albedo` | – | ERA5 forecast albedo (fal) |
| `snow_depth_cm` | cm | ERA5 physical snow depth (sd / rsn) |
| `imputed_share`, `ring_missing` | – | 1 where the corrected product fell back to raw CAMS / the CAMS ring was incomplete |
| `dni`, `zenith`, `azimuth_sun` | W/m², °, ° | closure DNI, solar position at the interval centre |
| `poa_global`, `poa_eff` | W/m² | capacity-weighted plane-of-array irradiance before / after shading and IAM |
| `t_cell` | °C | capacity-weighted cell temperature |
| `p_dc_raw_w`, `aging_factor`, `p_dc_w` | W, –, W | DC before aging/losses, aging factor, DC at the inverter |
| `clipped` | – | 1 where the inverter limits |
| `horizon_shaded` | – | share of beam blocked by the horizon |
| `snow_coverage`, `snow_factor` | – | snow coverage and resulting power factor |
| `power_park_free` | W | AC power before snow |
| `power_park` | W | `power_park_free × snow_factor` — the target |
| `availability` | – | placeholder 1.0 (the constant 0.98 is inside the chain; outage/curtailment masks are a later stage) |

Capacity for normalisation: `parks.csv:capacity_kw` = Σ MaStR Nettonennleistung (AC);
`capacity_kwp_dc` = Σ Bruttoleistung (DC).
